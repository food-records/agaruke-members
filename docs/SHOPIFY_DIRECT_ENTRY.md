Shopifyは現行customer accountsを使用する。メール認証はパスワード不要の6桁コード方式。既存プロフィールのメールでサインインすれば既存の注文情報を参照でき、新規メールならプロフィールを作る。**ゲスト注文で顧客IDが付いても、本人がShopifyへログインしたことにはならない**。既存メールと同じという理由だけでLINEを紐づけない。

メール配信同意、LINEの友だち状態、LINE認証、会員登録は別の情報。公開記念500円券の条件にこれらの配信同意・LINE連携を要求しない。

## 3. LINE連携の2方式と有効範囲

### 今回の購入だけ（ゲストでも可）

ショップの[会員・交換ページ](https://shop.agaruke.com/apps/members) →「LINEでポイントカードを使う」→ LINE認証 → 未登録なら会員登録と同意 →「同意してショップへ戻る」→ 現在のカートへ設定。

- Shopifyへのサインアップ/ログインは不要。
- 同じLINE会員の残高とEC交換券を利用できる。今回の注文は条件を満たせば100pt対象。
- 認証開始からショップへの戻りは10分以内。購入連携は24時間有効で、一注文に使用できる。
- カート・ブラウザが変わる、期限が切れる、購入済みになる場合は再認証が必要になる。ゲスト購入から継続連携は作らない。
- 期限内に注文が作成された場合は、支払い通知が遅れても注文作成時刻・カート等を照合して処理する。
- 開始ブラウザに本人確認用情報を保持する。端末/ブラウザをまたいで戻るだけの手動QR引継ぎは未対応。

### Shopifyアカウントへ継続連携

上記のLINE認証を行い、ショップ側でShopifyログイン済みと確認できた場合に保存する。会員ページの「アカウント・認証について」→「Shopifyアカウントと連携する」からログインする導線もある。

チェックアウトで初めてShopifyにログインした場合は、注文完了画面のブロックが署名付きの本人情報と注文通知を照合して継続連携する。注文通知の到着待ちでは「連携を再確認」を使う。

- 一対一の紐づけ。別のLINE会員/別のShopify顧客への上書き付替えは拒否する。マイページの「アカウント・認証について」から連携解除が可能。付替えは解除後に本人認証をやり直す。
- 次回、同じShopify顧客としてログインし、商品入りの**カート画面**を開くと、継続連携から新しい購入セッションを復帰させる。
- 継続連携がDBに存在するだけでは購入ptを付与しない。注文に有効な購入セッションが必要。
- セッションのない状態で直接会員ページを開くと、継続連携済みでもLINE認証の入口が表示される場合がある。現行の自動復帰はカートを起点とする。
- 商品ページの「今すぐ購入」（動的checkout）は2026-10-31に非表示へ変更。カートを経由して連携状態・券を確認する。ログアウト/別端末/別アカウントへの切替は受入確認対象。

### 交換券の獲得から利用まで

1. ショップの会員ページから本人のLINE認証を行う。
2. 「ポイントでクーポンに交換」を開き、200/500/1,000ptのいずれかを選ぶ。
3. 確認に同意するとポイントを減算し、個別のEC券を発行する。
4. 「お持ちのクーポン」、または商品/カート内の券一覧から選択する。
5. 最低額・期限等が成立すればカート/チェックアウトで値引きされる。選択・解除自体では追加pt消費なし。
6. 支払完了後、Members側でも使用済みとする。Shopify側は総利用1回を制限する。

残高不足なら交換不可。発行が途中で止まるとpendingとなり、会員ページの「発行を再開する」で同じ券を再開する。二重減算/別券の重複発行を防ぐ。交換の取り消しや、発行結果が曖昧な場合の自動ポイント返却はしない。

**本人限定の範囲:** 現行 `/apps/members` で発行する券は、Shopify顧客制限を付けずにゲスト対応している。本人LINE認証で獲得・一覧表示するが、**券コードを入手した人が利用できる方式**であり、チェックアウトでLINE認証を必須とする方式ではない。コードを第三者へ共有しない。利用されれば元の所有者の券を使用済みにする。旧顧客限定券・テスト券はこの扱いと異なる。

## 8. ポイント付与・取消条件

| 条件/出来事 | 現在の処理 |
| --- | --- |
| 購入前に有効なLINE購入連携を設定、JPY、実注文、正の支払額、paid確定 | 一注文につき100pt |
| 同じ日に2注文 | 別注文として条件を満たせば各100pt。ECには日次1回の制限なし |
| 公開券/交換券を使った注文 | 他の付与条件を満たせば100pt対象 |
| 注文作成のみ・未払い | 付与なし |
| 注文完了画面の表示/再読込 | それ自体では付与なし |
| 同一注文の通知再送・並行処理 | 追加付与なし |
| LINE未連携、退会会員、別カート/別顧客の不一致、0円注文、非JPY、テスト注文 | 対象外（test=trueのShopifyテスト注文は通常本番設定で除外） |
| 支払い完了前の取消、取消通知が先着 | 付与させない |
| 付与後の全額返金/注文取消 | 当該100ptを一度だけ減算 |
| 一部返金 | 一注文分の100ptを維持 |
| 全額返金時に残高を使用済み | 負残高を許容して取消。累積ランク用ポイントは減算しない |
| 交換済み券を使用した注文の取消/全額返金 | 使用券はvoid、交換ptの自動返却・券の自動再発行なし |
| 後日LINE連携した過去注文 | 遡及付与なし |

EC購入には「商品500円以上」という独自の最低購入額は実装していない。金額比例でも商品点数比例でもなく100pt/注文。支払い通知・有効セッションの照合を伴うため、画面表示直後の即時増加は保証しない。

100ptは利用可能残高と累積ランク用ポイントへ加算する。ログには取得時刻から1年の期限を保存し、規約も付与日から1年。ポイント失効の定期運用そのものの本番稼働は今回未監査なので、期限情報の保存と自動失効の実行を混同しない。

### 金額と残高の具体例

- 3種セット3,980円 → 公開500円券で商品3,480円。関東近郊送料990円なら合計4,470円。
- 同セット → EC200円券で商品3,780円。同送料なら合計4,770円。
- 2セット7,960円 → EC500円券で商品7,460円。
- **3セット11,940円はEC1,000円券の12,000円条件に届かない。送料を足して12,000円を超えても不可。** 単品1,280円を追加すれば商品13,220円となり、1,000円引き後12,220円。
- 交換前残高Pで200pt券を取得→P−200、対象の支払完了→P−100、全額返金→P−200。交換した200ptは自動返却しない。

## 9. 実アカウント受入試験

結果欄は未記入。過去の一部確認済み項目も、最終構成で再確認するためのチェックリスト。実決済・返金・追加交換はユーザーが行う。確認中に別作業で設定を変更した場合は、時刻と版を記録して再判定する。

### 準備

- 一般券の未使用顧客、既存LINE会員、未連携の新規LINE会員等を区別する。別のLINE/Shopifyへ付替える試験は正規のペアを壊さない組合せで行う。
- メール/顧客、端末・ブラウザ、Shopifyログイン、LINE会員/継続連携、開始残高、券名/期限、注文番号、支払/返金状態、期待差分、実測差分を記録。秘密の券コード/トークンは共有Gitへ書かない。
- 3種のEC券を各1枚新規交換する場合は合計1,700ptを消費する。残高がなければ不足時拒否までを確認し、成功試験用残高の用意は別途決める。無断で本番ptを増やさない。

# オープン記念500円券の使用済み表示（2026-10-31）

Shopifyログイン済みの顧客の支払い済み使用履歴を確認し、商品・カート・ショップ会員ページの500円券を「使用済み」として選択不可にする。選択中ならAGARUKE500だけを除去し、他の割引コード/カート商品/購入用LINE連携属性は維持。カートでは除去後に再読込して価格表示も更新する。

## 判定と境界

- 既存の署名付きapp proxyへlaunch_statusを追加。本人は署名済logged_in_customer_idだけで識別し、ブラウザー指定の顧客ID/LINE UIDは使わない。Origin/JSON/サイズ/時刻/ストア照合は既存どおり。
- 既存Admin read_orders/read_customersで、customer_id・discount_code:AGARUKE500・status:any・キャンペーン期間を含む2026-10-01以降に限定した注文を最大10件だけ読む。追加権限・全件scan・DB index/定期Job/有料アプリなし。既存権限で#1001顧客のused判定を読取確認済み。割引併用不可の券なので、注文検索が最初の割引コードだけを対象とする制約にも抵触しない。
- 取得した各注文の顧客GIDとコードを再照合。不一致/GraphQLエラー/通信失敗はunknown。PAID/PARTIALLY_REFUNDEDの使用履歴があれば、キャンセル表示が付いていてもused。未払い取消・全額返金・支払保留等だけならunknownとして使用済みを断定しない。該当なしはnot_used。注文詳細/個人情報はブラウザーへ返さない。
- Shopify未ログインはguest。LINE会員だけを根拠に一般券を使用済み扱いにしない。直接入力/ゲストの最終制限はShopifyの1人1回が継続して担当。
- 処理はクーポン一覧を開く時、会員ページ入場、選択中の500円券を検出した時と選択直前に実行。同時の確認をまとめる。ブラウザー内だけの状態で、永続的な使用済みフラグは保存しない。復帰時に再確認し、古いアカウントの遅い応答で状態を巻き戻さない。確認中は選択ボタンを一時無効にする。
- 使用済み/期限切れと確認できれば選択を拒否。通信は12秒でunknownへ戻し、unknown/guestでは一律に購入を禁止しない。購入手続きで最終判定される。
- 商品額不足だけでなく使用済み/期限等もあり得るため、利用不可状態を「利用不可」「選択中（利用できません）」と表示する。

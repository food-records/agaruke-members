# トップ文言の管理画面編集（2026-10-31）

## 編集方法

Shopify管理画面 → オンラインストア → テーマ → 公開中の「Dawn · AGARUKE Home」をカスタマイズ → ホームページ。

- 「AGARUKE メインビジュアル」：画像、画像の代替テキスト、VIEW ITEMの文言/リンク、下の案内3件。日本語・英語欄をそれぞれ編集。
- 「AGARUKE サービス紹介」配下の各ブロック：サービス紹介、食べ方の見出し、食べ方①〜③、商品エリアの文言、自分の時間の紹介、はじめての方へ、FAQ、LINEカードの案内、ページ下部CTA。
- 各欄の「（日本語）」「（英語）」を入力して保存。トップの翻訳は同じテーマ画面の入力欄が正本。Translate & Adapt/CSVは不要。
- FAQは質問・回答を日英で入力。FAQ同士の並べ替え・追加・削除に対応。本文の改行は表示へ反映される。既存のPC/mobile専用改行も維持。
- おすすめ商品は商品選択と日英の短い紹介文を編集可能。英語の短文が空欄なら英訳済み商品説明の抜粋を表示。商品名/価格/画像は商品管理の正本を参照し、重複入力しない。
- 商品そのものの日英名称/説明は従来どおり商品管理＋native英語翻訳。通常の固定ページも別のページ管理を使う。
- 日本語を変えても英語は自動更新されない。両欄を確認する。

## 実装と移行

section2件と共通のagaruke-copy snippetが、現在言語に対応する設定欄を選択。HTMLはescapeし改行だけbrへ変換。画像/商品3件/順序/既存短文/アンカー/透明header/レイアウトを維持。大項目の位置はデザイン上固定、商品同士とFAQ同士の順序は編集可能。

既存のschema内localeから現在の日英コピーを各blockへ移す。運用snapshot/index JSONはGit外保護runtime shopify-editable-20261031。`tools/theme-editable-content.py`は取得済みテーマに対するローカル処理で、既存の商品/画像設定を保持し、移行済みなら文言を初期化しない。未知/一部移行状態は失敗させる。移行の冪等性・商品選択/順序/短文・画像設定の保持を検証済み。

変更対象：section2件/snippet1件/templates/index.json。LINE/カート/クーポン/バックエンド/試験modeには変更なし。新規課金構成・商品更新・注文操作なし。
